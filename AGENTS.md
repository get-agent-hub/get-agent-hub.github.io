# Repository instructions

- Keep the website and repository documentation in English. All website copy, metadata, accessibility labels and demo messages belong in `locales/en.json`.
- English is the only active language for now. Translation PRs may add complete locale files following `CONTRIBUTING.md`; do not activate another language without a maintainer request.
- Deployment is maintainer-managed. Do not deploy to GPT/Sites, push source to its hosting repository, or publish to another host unless the user explicitly requests that action. Local builds and checks are allowed.
- The existing `.openai/hosting.json` identifies a previously created private preview. Its presence does not authorize future publication or access changes.
- Keep demonstrations fictional. Never run Agent Hub operations against a visitor's computer or include real user configurations, credentials or recovery files in the site.
