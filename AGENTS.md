# Repository instructions

- Keep repository contributor notes in English; website and rendered documentation ship in English and Russian. All website copy, metadata, accessibility labels and demo messages belong in locale files under `locales/`. English is the reference schema.
- English and Russian are active, as requested by the maintainer. Translate both the landing and documentation; preserve executable syntax and stable page/anchor routes. Other language activation still requires a maintainer request.
- Deployment is maintainer-managed. Do not deploy to GPT/Sites, push source to its hosting repository, or publish to another host unless the user explicitly requests that action. Local builds and checks are allowed.
- Local `.openai/` files can identify an old private preview. They are ignored and excluded from publication source; they do not authorize publication or access changes.
- Keep demonstrations fictional. Never run Agent Hub operations against a visitor's computer or include real user configurations, credentials or recovery files in the site.
